# Chipopo releases

Public installers for **Chipopo** (West's AI Team app).

This repo holds **release assets only**: the Windows installer (`.exe`), its `.blockmap`, and `latest.yml`. No source code lives here — the app code stays in the private `ArtificerKeys/AI-Team-App` repo.

The Chipopo app's update button reads `releases/latest` from this repo. Do not upload source, drafts, or pre-releases for production updates.
